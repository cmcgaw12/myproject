            <h2>Abstract</h2>
            <p>
                Hypertext Transfer Protocol (HTTP) is an important
                technology that allows web browsers and servers to
                communicate. It is used whenever users access web
                pages, images, videos, and other online resources.
                This website explores how HTTP works, its common
                methods and status codes, and the differences
                between HTTP and HTTPS.
            </p>
        </section>

        <section>
            <h2>Key Terms</h2>
            <ul>
                <li><strong>HTTP:</strong> A protocol used to exchange
                    information between clients and servers.</li>
                <li><strong>Client:</strong> A device or application
                    that requests information, such as a web browser.</li>
                <li><strong>Server:</strong> A system that receives
                    requests and provides responses.</li>
                <li><strong>Request:</strong> A message sent by a client
                    asking for a resource or action.</li>
                <li><strong>Response:</strong> A message returned by
                    a server, often containing a status code and data.</li>
                <li><strong>HTTPS:</strong> HTTP communication protected
                    by TLS encryption.</li>
            </ul>
        </section>
